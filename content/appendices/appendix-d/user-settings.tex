\section*{User Settings}
\addcontentsline{toc}{section}{User Settings}

Symphony's user settings provide global configuration that applies across all workspaces and projects. Settings are stored in TOML format for human readability and version control compatibility.

\subsection*{Settings File Location}

User settings are stored in platform-specific locations:

\begin{description}[leftmargin=4cm,labelwidth=3.5cm]
\item[\textbf{Windows}] \texttt{\%APPDATA\%\textbackslash Symphony\textbackslash settings.toml}
\item[\textbf{macOS}] \texttt{\textasciitilde/Library/Application Support/Symphony/settings.toml}
\item[\textbf{Linux}] \texttt{\textasciitilde/.config/symphony/settings.toml}
\end{description}
